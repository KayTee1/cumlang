# CumLang

CumLang is a cutting-edge research project investigating the fundamentals of programming language design, compiler architecture, and the limits of developer dignity.

This project explores how programming languages actually work under the hood by implementing core components such as lexical analysis, parsing, transpilation, and compilation.

The language intentionally uses questionable syntax while implementing real compiler concepts in order to make the learning process both educational and entertaining.
